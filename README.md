### Flutter Web Setup

To enable web support and run this project on the web:

1. **Enable web support:**
    ```bash
    flutter config --enable-web
    ```

2. **Run on web:**
    ```bash
    flutter run -d chrome
    ```

3. **Build for web:**
    ```bash
    flutter build web
    ```
